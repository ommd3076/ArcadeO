## Overview
Implemented server-authoritative preferences and account records projections:
1. `GET /api/v1/profile`: Fetches safe profile for the authenticated session alongside the opponent's safe profile and distinct accent configuration.
2. `PATCH /api/v1/profile/preferences`:
   - Validates CSRF token.
   - Enforces optimistic concurrency via `preferenceVersion`.
   - Enforces the hard atomic constraint that Player A and Player B cannot select the same accent color family (`distinct-accents` constraint).
   - Updates account preferences in D1 and increments `preferenceVersion`.
3. `GET /api/v1/records/summary`:
   - Computes head-to-head match stats between Player A and Player B.
   - Computes active win streaks in chronological order based on `finishedAt`.
   - Computes Asia/Calcutta (+05:30) Monday-anchored weekly matches count and wins.
   - Groups match stats by game.
   - Retrieves best unassisted and assisted Sudoku completion times across puzzle buckets.
4. `GET /api/v1/records/recent`:
   - Lists recent completed matches from the `results` projection with pagination.
