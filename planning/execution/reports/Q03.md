## Overview
Comprehensive review of design tokens, four appearance variants, safe-area ergonomics, touch targets, and motion behavior:
1. **Four Appearance Variants**:
   - **Standard Dark**: Canvas `#0C0C0F`, Surface `#1C1C20`, Text `#F5F5F7`, mint `#CFE6A3`, cyan `#A8DFE4`, warm yellow `#F4DE88` accents.
   - **Standard Light**: Canvas `#F7F7F8`, Surface `#FFFFFF`, Text `#17171C`, mint `#CFE6A3`, cyan `#A8DFE4`, warm yellow `#F4DE88` accents.
   - **Romantic Dark**: Canvas `#120C1C`, Surface `#21152E`, Text `#F6F0FF`, moody purple `#C9A7FF` fill, violet/pink tonal accents.
   - **Romantic Light**: Canvas `#FFF5F8`, Surface `#FFE5EE`, Text `#301A2C`, elegant pink `#9A305E` fill, pink/rose tonal accents.
2. **Player Piece Accent Independence**:
   - Player piece colors (teal `#68D6C2`, violet `#C5A2FF`, cyan `#67E8F9`, mint `#86EFAC`, pink `#F472B6`, yellow `#FDE047`) remain independent of the chosen theme family and theme mode.
   - Player A and Player B cannot select the same accent color (enforced in both UI and backend).
3. **Ergonomics & Touch Targets**:
   - All interactive touch targets (board cells, drop buttons, dice rolls, secret choices, navigation tabs, back header, S/O selectors, number pad keys) maintain `>= 44x44px` physical hit areas.
   - Safe areas handled via CSS variables `--sat`, `--sab`, `--sal`, `--sar` derived from `env(safe-area-inset-*)`.
   - Header is sticky top with Back action preserving match state; bottom navigation tabs appear only on primary tabs.
4. **Motion & Accessibility**:
   - CSS transitions for tactile press feedback (`scale(0.96)`, `150ms cubic-bezier(0.2, 0.8, 0.2, 1)`).
   - Disc drop gravity animations (`300ms cubic-bezier(0.16, 1, 0.3, 1)`).
   - `@media (prefers-reduced-motion: reduce)` override ensures instantaneous state updates without motion sickness triggers.
