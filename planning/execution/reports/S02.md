# Task Report: S02 - Sudoku Rules and Private Server Modes

- **Task**: S02
- **Role**: sudoku-engineer

## Owned Paths and Files Changed
- `shared/games/sudoku/types.ts`: Pure Sudoku state, actions, undo records, viewer context, effects, and public views conforming to protocol specifications.
- `shared/games/sudoku/engine.ts`: Deterministic pure reducer for Sudoku:
  - Immutable givens validation.
  - Cell digits (`1..9`), erasing, and note bitmasks (`1 << digit`).
  - Automatic clearance of cell notes on digit placement; no automatic peer note removal.
  - Undo stack restoring previous digit and notes without rewinding clock, assistance, or completion.
  - Practice mode explicit Pause/Resume and Check marking `assisted: true` permanently.
  - Automatic win detection upon matching verified solution.
  - Duel mode synchronized start (+3s) and strict privacy filtering (opponent view reveals only `filledCount: number`, never cell entries, correctness, or notes).
  - Async challenge mode sender timing, published challenge, and receiver whole-second comparison (`floor(senderMs / 1000)` vs `floor(receiverMs / 1000)` with equal-second draws).
- `shared/games/sudoku/adapter.ts`: Implementation of `GameEngineAdapter` for Sudoku engine auto-registration.
- `worker/sudoku/catalog.ts`: Public catalog querying from `content/sudoku/catalog.json`, listing by bucket (`easy`, `medium`, `hard`, `expert`), uncompleted puzzle eligibility resolution, and exhausted-catalog replay labeling.
- `worker/sudoku/verification.ts`: Server-only solution repository queries from `content/sudoku/solutions.json` and verification helpers.
- `worker/sudoku/records.ts`: D1 `sudoku_records` projection helper (`projectSudokuRecord`), unassisted best time query (`getBestUnassistedTime`), and completed puzzle ID lookup (`getCompletedPuzzleIds`).
- `worker/sudoku/index.ts`: Unified worker sudoku exports.
- `tests/unit/games/sudoku/sudoku.test.ts`: 12 automated unit tests covering SUD01–SUD08 requirements:
  - Givens immutability.
  - Note bitmasks and setting clears cell notes.
  - Undo stack restores past edits and notes.
  - Practice Check permanent assistance marking and Pause timer masking/edit rejection.
  - Duel +3s synchronized start and strict privacy filtering (zero opponent cells/notes leaked).
  - First-to-finish duel win detection.
  - Async challenge whole-second comparison and draw on equal seconds.
- `tests/integration/sudoku/sudoku.test.ts`: 7 automated integration tests covering:
  - Safe catalog querying without private solutions.
  - Uncompleted puzzle eligibility and bucket exhaustion replay.
  - Private solution verification.
  - D1 `sudoku_records` projection and unassisted best time queries.
  - Duel +3s synchronized start holding givens and moves until start time.
  - Continuous competitive clock advancing through background/disconnect.
  - Full async challenge flow: sender finish, publish, receiver accept, continuous attempt, and whole-second draw comparison.

## Findings and Limits
- Givens and private solutions are strictly kept server-side; in duel mode, givens remain masked as 81 zeroes until the server scheduled start time (`+3s`) arrives.
- In both duel and challenge modes, opponent views expose strictly `filledCount`, never cell digits, correctness, or notes.
- In async challenges, comparisons use `floor(senderElapsedMs / 1000)` and `floor(receiverElapsedMs / 1000)` to produce fair whole-second ties.
- Continuous clock in competitive modes calculates elapsed time directly from `serverTime - startedAt`, preventing background or disconnection from stopping or resetting the timer.
